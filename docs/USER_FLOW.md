# User flow — Milestone 07

1. 「サンプルで試す」または自分の2048×2048 PNGを選ぶ。
2. プレビューを確認し、ダンスを選んでPlay。速度と背景は任意で調整。
3. 「WebM動画を作成」を押し、完了後「動画を保存」。

初期画面はサンプルを主導線にする。サンプルは同一サイトの静的PNGを取得し、
Fileに変換して通常のValidator → Parser → Skeleton経路に渡す。
サンプルを選ぶたびにCute Dance / 1.0x / Darkへ戻し、自動再生しない。
通常の再アップロードでは速度・背景・ダンスの選択を保持する。
同時選択と画面終了時には古い読み込みを無効化し、静的ファイル取得を中断する。

テンプレート取得と画像仕様はアップロード欄に配置する。画像はブラウザ内で処理し、
サーバーに送信しない。Debugは通常導線の下に置き、初期状態は閉じる。
動画作成中はサンプル選択もロックする。成功・失敗・キャンセルは画面上に表示する。

ブラウザ名で出力可否を決めず、captureStream / MediaRecorderとWebM MIME対応を
実行時に判定する。Chrome / Edge / Firefox / Safariでもこの同じ経路を通す。
対応形式がなければ出力ボタンを無効化し、ダンスのプレビューは引き続き利用できる。
WebM非対応環境への変換やpolyfillは導入しない。
